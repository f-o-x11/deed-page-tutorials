A CLAUDE.md rule that shares HTML only after you say yes

Claude Code will happily turn a coverage dump, a design memo or a one-page standup board into HTML. Getting that file onto a public URL is still a detour: zip, upload, paste. This walkthrough adds a short rule to CLAUDE.md plus a two-step shell script, so you can say "share status.html" and Claude waits for your yes before anything leaves the machine. No MCP install required — just shell and a rule file.

Where the rule lives

Claude Code reads CLAUDE.md in the project root, and a global file at ~/.claude/CLAUDE.md if you keep one. A personal sharing habit belongs in the global file; put a project-only variant in the repo when a team wants the same gate. Keep the script at ~/.claude/bin/share-html.sh (or scripts/share-html.sh in a repo) and mark it executable.

Two calls, not a prompt

Do not put read -p "Publish?" in the script. The agent terminal is not a session you are watching, and the model can answer itself. Split the work:

  1. share-html.sh status.html prints path, byte size and the page <title>, warns that publishing makes it public, and exits. Nothing is uploaded.
  2. share-html.sh status.html --confirmed uploads and prints the live URL.

The CLAUDE.md text below tells Claude that the second form is allowed only after you reply yes in chat. If network is sandboxed, the upload needs a separate approval, which is a useful second checkpoint.

The script

It publishes with deed.page: one curl -T, no account. The first upload returns an owner token; the script stores it under ~/.config/deed-page/token (mode 600) and masks it in stdout so it never lands in the Claude transcript. A small map file remembers which slug belongs to which local path, so a second share updates the same address.

#!/usr/bin/env bash
# share-html.sh FILE [--confirmed]
# Without --confirmed: preview only (size + title). With --confirmed: publish.
# Agents may pass --confirmed only after the human said yes in chat.
set -euo pipefail
FILE=${1:-}; MODE=${2:-}
[[ -n "$FILE" && -f "$FILE" ]] || { echo "usage: $0 FILE [--confirmed]" >&2; exit 2; }
TITLE=$(grep -oim1 '<title>[^<]*' "$FILE" 2>/dev/null | sed 's/<title>//I' || echo "(no title)")
SIZE=$(wc -c <"$FILE" | tr -d ' ')
echo "File: $FILE"
echo "Size: $SIZE bytes"
echo "Title: $TITLE"
echo "Publishing makes this file public on the internet."
if [[ "$MODE" != "--confirmed" ]]; then
  echo "Preview only. Re-run with --confirmed after the human says yes in chat."
  exit 0
fi
mkdir -p "$HOME/.config/deed-page"
chmod 700 "$HOME/.config/deed-page"
MAP="$HOME/.config/deed-page/slug-map"
TOKEN_FILE="$HOME/.config/deed-page/token"
BASE=$(basename "$FILE"); BASE=${BASE%.*}
SLUG=$(awk -v f="$FILE" '$1==f{print $2; exit}' "$MAP" 2>/dev/null || true)
[[ -n "$SLUG" ]] || SLUG=$(echo "$BASE" | tr '[:upper:]' '[:lower:]' | tr -cd 'a-z0-9-' | cut -c1-40)
[[ -n "$SLUG" ]] || SLUG="page-$RANDOM"
AUTH=(); [[ -f "$TOKEN_FILE" ]] && AUTH=(-H "Authorization: Bearer $(cat "$TOKEN_FILE")")
RESP=$(curl -sS -D /tmp/deed-headers -o /tmp/deed-body -w "%{http_code}" \
  -T "$FILE" "${AUTH[@]}" "https://deed.page/v1/sites?slug=$SLUG")
BODY=$(cat /tmp/deed-body)
echo "$BODY" | grep -o '"url"[[:space:]]*:[[:space:]]*"[^"]*"' | head -1 || echo "$BODY"
# Save token if present; never echo it.
python3 - "$BODY" "$TOKEN_FILE" <<'PY'
import json,sys,os
body, path = sys.argv[1], sys.argv[2]
try:
  d=json.loads(body)
except Exception:
  sys.exit(0)
tok=d.get("token") or d.get("ownerToken")
if tok:
  os.makedirs(os.path.dirname(path), exist_ok=True)
  open(path,"w").write(tok); os.chmod(path,0o600)
PY
ABS=$(cd "$(dirname "$FILE")" && pwd)/$(basename "$FILE")
touch "$MAP"; grep -v "^$ABS " "$MAP" >"$MAP.tmp" || true
echo "$ABS $SLUG" >>"$MAP.tmp"; mv "$MAP.tmp" "$MAP"
echo "HTTP $RESP"

Drop this into CLAUDE.md

## Sharing HTML / static pages
- When I ask to share a page, run `~/.claude/bin/share-html.sh PATH` (no --confirmed).
  Show me the preview (path, size, title) and ask: "Publish this to a public URL?"
- Only after I reply yes in this chat, run the same command with `--confirmed` and
  give me the URL. Never publish on your own.
- Never print, cat or paste an owner token from ~/.config/deed-page/ or from command output.

What a good turn looks like

You: "Share coverage/index.html with the team."
Claude: runs the preview, shows size/title, asks for yes.
You: "yes"
Claude: runs with --confirmed, returns a https://….deed.page/ URL.

Edit the file later and ask again; the slug map updates the same address when your saved owner token is present (Claude must not read that file).
